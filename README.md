# 🧠 Kioku Engine
Kioku Engine es un pipeline de datos personales ligero y un rastreador de métricas de estudio. Inicialmente concebido como un motor de grafos, el proyecto pivotó hacia una arquitectura minimalista (Python + SQLite) enfocada en la eficiencia. Su objetivo principal es registrar, analizar y optimizar mis sesiones de estudio de idiomas y mi progreso académico general, manteniendo la flexibilidad para servir como portafolio técnico en futuras postulaciones a programas internacionales.
